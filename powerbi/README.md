# Power BI Dashboard – MED-AR-001

This folder contains the Power BI dashboard for the Medical Billing Denial & Accounts Receivable Analytics project.

**Dashboard file:** `MED-AR-001_Final_Dashboard.pbix`

The dashboard presents:
- Claims and denial KPIs
- Denial trends and categories
- Payer performance
- Revenue at risk
- Accounts receivable aging
- SLA compliance
- Appeal timeliness
- Average days in AR

**Tool:** Microsoft Power BI Desktop
